# Семейный органайзер — стартовый проект (Android)

Это настоящий Android Studio проект (Kotlin + Jetpack Compose), написанный по
плану из `family-app-architecture.md` и макету `family-app-mockup.html`.
Я не смог собрать APK прямо в облачной песочнице, где писал этот код: у неё
нет доступа к серверам Google (Android SDK, репозиторий зависимостей Compose)
— она разрешает только несколько пакетных реестров вроде npm/pypi. Поэтому
сборка настроена через **GitHub Actions**: код собирается на серверах
GitHub, у которых такого ограничения нет.

## Что уже работает

- Общая навигация (нижнее меню): Дашборд, Финансы, Задачи, Покупки, Ещё.
- Тема оформления — та же цветовая палитра, что в HTML-макете, светлая и тёмная.
- **Покупки** — полностью рабочий экран: добавление товара, отметка «куплено»,
  удаление. Хранится локально на телефоне (Room), из коробки переживает
  перезапуск приложения.
- Дашборд / Финансы / Задачи / Ещё — пока экраны-заглушки («скоро здесь
  будет…») — по образцу «Покупок» их несложно достроить дальше, см. раздел
  «Следующие шаги» ниже.

Специально нет синхронизации между телефонами членов семьи — это Firebase
(Firestore), про которую в плане архитектуры сказано отдельно. Firebase
нельзя было настроить за вас: для этого нужен ваш Google-аккаунт и создание
проекта в консоли Firebase (см. ниже).

## Как получить APK и поставить на телефон

### 1. Создайте пустой репозиторий на GitHub

На github.com → **New repository** → дайте имя (например `family-organizer`)
→ **не** отмечайте «Add a README» / «.gitignore» / «license» (они уже есть в
присланном архиве) → **Create repository**.

### 2. Загрузите код проекта

Распакуйте присланный архив и в терминале, в папке проекта, выполните:

```bash
git init
git add .
git commit -m "Первая версия приложения"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
git push -u origin main
```

(Если непривычно работать с git из терминала — то же самое умеет делать
GitHub Desktop: File → Add Local Repository → выбрать папку → Publish.)

### 3. Дождитесь сборки

Откройте вкладку **Actions** в репозитории на GitHub — сборка запускается
автоматически после push (или нажмите «Run workflow» вручную, если что-то
пошло не так). Займёт обычно 3–6 минут. Зелёная галочка = собралось.

### 4. Скачайте APK

Откройте завершившийся workflow run → внизу страницы, в разделе
**Artifacts**, будет `family-organizer-debug-apk` — скачайте его (это zip,
внутри лежит сам `app-debug.apk`).

### 5. Установите на телефон

Перекиньте `app-debug.apk` на Android-телефон любым удобным способом
(отправить себе в Telegram/почту, залить в Google Диск, по USB-кабелю).
Откройте файл на телефоне — Android спросит разрешение «Установить из
неизвестного источника» (это ожидаемо для APK не из Google Play), нужно
разрешить для приложения, через которое открываете файл. Дальше — обычная
установка.

## Если сборка в Actions упадёт с ошибкой

Я подобрал версии Kotlin/AGP/Compose/Room вручную, без возможности
проверить сборку на месте (см. причину выше) — есть небольшой шанс, что
какая-то версия не сойдётся с другой. Обычно это видно сразу в логе шага
«Build debug APK» одной понятной строкой про несовместимость версий.
Пришлите мне текст ошибки — поправлю версию за один шаг.

## Разработка локально в Android Studio

Открыть папку проекта в Android Studio → она сама подхватит Gradle wrapper
(`gradlew`) и синхронизируется, используя ваш обычный интернет (без
ограничений песочницы) → **Run ▶** запустит приложение на эмуляторе или
телефоне, подключённом по USB с включённой отладкой.

## Следующие шаги (по плану из family-app-architecture.md)

1. **Firebase** — создать проект на console.firebase.google.com, включить
   Firestore и Authentication, добавить `google-services.json` в `app/` —
   тогда «Покупки» (и остальные модули) смогут синхронизироваться между
   телефонами членов семьи в реальном времени.
2. Достроить по образцу «Покупок» остальные модули: Задачи, Финансы (с
   категориями и накоплениями), Календарь, Цели, Желания — используя те же
   слои (Entity → DAO → Repository → ViewModel → Compose-экран).
3. Дашборд — собрать из виджетов остальных модулей, когда они появятся.
4. Перейти с ручного DI на Hilt (было в исходном плане, упростил для первой
   сборки — см. `FamilyOrganizerApp.kt`).
5. Перед публикацией в Google Play — включить `isMinifyEnabled`, подписать
   релизную сборку своим ключом, нарисовать полноценную иконку.
